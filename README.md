# MOTIVA — Modern Editorial

Обновлённая версия исходного проекта на HTML, CSS и JavaScript. Сборщик и сторонние библиотеки не нужны.

## Запуск

1. Распакуйте архив целиком.
2. Откройте папку `motiva`.
3. Запустите `index.html` в современном браузере.

Для корректной работы системного меню «Поделиться» браузер может требовать HTTPS или localhost. Если функция недоступна, кнопка предложит скопировать цитату и ссылку.

## Что изменено

- Обновлена визуальная система: графитовая типографика, коралловый акцент, более выразительная композиция и карточки.
- Рисованные SVG-портреты заменены реальными фотографиями авторов: ссылки на Wikimedia Commons вынесены в поле `photo` каждого автора в `data.js`. При недоступности сети или ошибке загрузки автоматически показывается прежняя SVG-иллюстрация (фолбэк в `app.js` + `svgPortraitSrc()` в `portraits.js`). Для пословиц фото нет — там остаётся иллюстрация.
- Русский перевод стал основным текстом: он крупно показывается в карточках, в блоке «мысль на сегодня» и в заголовке страницы цитаты, а оригинал — строкой ниже («Оригинал: …»).
- Блок подробной информации на странице цитаты собран в строку: метки и значения идут сплошным текстом с разделителями вместо вертикального списка пар.
- Добавлен блок подбора цитат по текущему запросу/настроению через существующие тематические категории.
- Добавлена стабильная «мысль на сегодня»: одна и та же цитата показывается в течение календарного дня.
- Добавлена кнопка «Поделиться» на странице цитаты с резервным копированием текста и ссылки.
- Добавлена понятная пустая выдача и сброс поиска, темы и избранного.
- Улучшена мобильная компоновка панели поиска, фильтров, карточек и страницы цитаты.
- Добавлена проверка сохранённых избранных ID и допустимого значения темы при загрузке.
- Сохранены исходные формулировки цитат, атрибуции, маршрутизация, избранное и переключение темы.

## Портреты авторов

Фотографии подгружаются с Wikimedia Commons по прямой ссылке (`Special:FilePath/...?width=480`) — файлы не хранятся в проекте, поэтому для их показа нужен доступ в интернет. Без сети сайт работает как раньше: вместо фото рисуется SVG-портрет по описанию автора. Подпись под фото на странице цитаты указывает источник — «Фото: Wikimedia Commons».

Что заменить или добавить фото: измените `photo` у автора в `data.js`. Пустое поле означает «показывать иллюстрацию».

## Файлы

- `index.html` — структура страниц.
- `styles.css` — оформление и адаптивность.
- `app.js` — поиск, фильтры, маршрутизация и интерактивность.
- `data.js` — исходная коллекция цитат и сведения об источниках.
- `portraits.js` — генерация портретных иллюстраций.

## Важно о содержании

Существующие цитаты и атрибуции сохранены без автоматической правки: для проверки фактов нужно отдельно сверить каждую формулировку с первоисточником. Статусы достоверности в интерфейсе следует выставлять только после такой проверки.
